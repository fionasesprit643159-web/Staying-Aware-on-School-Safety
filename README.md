# Shooting Safety Maps

Dependency-free browser pages for the Shooting Safety landing flow and its classroom, bathroom, outdoor, and simulation maps.

## Structure

- `index.html` — app landing page
- `pages/` — information, map-selection, and map pages
- `styles/` — page stylesheets
- `scripts/` — navigation and interaction scripts
- `assets/images/` — image assets
- `.vscode/` — editor-only launch configuration
